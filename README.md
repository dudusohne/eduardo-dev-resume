# Eduardo — Resume

Personal portfolio built with Next.js, TypeScript, and Tailwind CSS.

## Languages

The portfolio is available in English (`/en-US`) and Brazilian Portuguese (`/pt-BR`).
English is the default language, and visitors can switch languages from the header.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Commands

- `npm run dev` — starts the development server.
- `npm run build` — creates the production build.
- `npm run lint` — checks code quality.
- `npm run format` — formats the project with Prettier.
